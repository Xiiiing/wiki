# 论文归档

每篇论文对应一个独立 Markdown，按研究问题、方法、实验设置、主要结果及消融讨论整理。已有笔记保留原内容，并在原文件补充。

本批收藏共 123 份 PDF，合并重复副本和早期版本后对应 116 篇独立论文；其中 99 篇 WSI 论文属于 2024–2026 年，16 篇为相关 MIL 方法，另有 TOP 的年份应为 2023。图表从原 PDF 中选取，页面中注明 PDF 页码。

实验设置、数值和结论均根据原论文记录，未重新运行作者代码。部分发表归属仍待核对，沿用简介页中的标注；裁剪不可靠的图表未放入笔记。
