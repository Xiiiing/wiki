## 关于这本知识库

这里保存学习过程中值得留下来的东西：读过的论文、梳理过的方法、解决过的工程问题，以及暂时还没有答案的思考。

内容围绕计算机视觉与医学影像展开，也延伸到算法、开发工具和日常实践。笔记随学习持续整理，方便查找、补充和重新理解。

## 记下什么

| 分类 | 内容 |
| --- | --- |
| [科研与医学](https://xiiiing.github.io/wiki/Research/) | 数字病理、全切片图像、多实例学习，以及相关论文与研究方法。 |
| [算法与数据结构](https://xiiiing.github.io/wiki/Algorithm/) | 基础算法、常用数据结构和解题过程中的理解与总结。 |
| [开发与工程](https://xiiiing.github.io/wiki/Development/) | 开发工具、环境配置与工程实践中遇到的问题。 |
| [随笔](https://xiiiing.github.io/wiki/blog/) | 学习过程中的观察、阶段记录和零散想法。 |
| [建站记录](https://xiiiing.github.io/wiki/About/) | 这座个人站点的搭建与调整过程。 |

## 从一个问题开始

可以沿着分类导航阅读，也可以直接搜索一个术语、工具或问题。文章之间通过链接相互补充，较长的笔记可以借助页内目录定位。

如果想先了解我，欢迎回到 [个人主页](https://xiiiing.github.io/)；如果想换个方向看看界面与交互，可以逛逛 [UI Design Atlas](https://xiiiing.github.io/ui-design-atlas/)。
