# Xiiiing's Wiki

站点：[xiiiing.github.io/wiki/](https://xiiiing.github.io/wiki/)

个人主页：[xiiiing.github.io](https://xiiiing.github.io/)

本仓库从 `Xiiiing/Xiiiing.github.io` 的 `fa720e9` 迁移，保留此前完整的提交历史。

## 本地预览

使用 Python 3.12，安装 `requirements.txt` 后运行 `python -m mkdocs serve`。
由于站点位于子目录，预览地址为 `http://127.0.0.1:8000/wiki/`。

推送到 `main` 后，GitHub Actions 独立构建并发布 Wiki。
